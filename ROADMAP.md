# Roadmap

## Short-term
- Flesh out Tabular CDE architectures and training loops.
- Provide dataset utilities for common benchmarks.
- Publish documentation website with tutorials.
- Prototype multi-bandwidth heads for adaptive smoothing.
- Explore conditional bandwidth predictors that modulate sharpness per sample.

## Mid-term
- Add probabilistic calibration metrics and visualizers.
- Support Lightning / Torch.compile training pipelines.
- Release pip and conda packages.
- Design a monotone CDF head that enforces invertibility without numerical fixes.

## Long-term
- Integrate with the broader Condensite platform for production deployment.
- Provide AutoML-style search over estimator architectures.
